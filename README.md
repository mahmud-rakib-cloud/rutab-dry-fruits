
# Rutab Dry Fruits

Premium Dry Fruits E-commerce Website

Welcome to Rutab Dry Fruits — your destination for quality dates and premium dry fruits.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Technology

- Next.js
- TypeScript
- Tailwind CSS
